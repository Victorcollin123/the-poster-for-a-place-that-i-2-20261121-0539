VELMARA — a travel poster for a lantern-lit harbour town on a tideless glass sea, a place that does not exist. The poster's one landmark is the Lantern Tower, its light spilling over the glass-calm water at dusk. The image is drawn programmatically with Python and PIL (`build_image.py`); `main.py` copies it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
